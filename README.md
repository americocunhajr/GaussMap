**GaussMap** is an easy to run code to simulate the chaotic dynamics of a generalized version of the classical Gauss Iterated Map. The implementation follows an educational style, to make its use very intuitive.

## Software History

This code was developed to conduct simulations of a generalized version of the classical Gauss Iterated Map. The underlying results are reported in the following paper:
- *A. Cunha Jr ...*

## Documentation

**GaussMap** routines are commented in order to explain their functionality to the final user. Each routine has a short description about its purpose, and a list of inputs and/or outputs.
