**GaussMap** is an easy-to-run code to simulate the chaotic dynamics of a generalized version of the classical Gaussian Iterated Map. The implementation follows an educational style, to make its use very intuitive.

## Software History

This code was developed to simulate a generalized version of the classical Gaussian Iterated Map. The underlying results are reported in the following paper:
- *A. Cunha Jr, The generalized Gaussian iterated map, 2026*

Preprint at ArXiv:
XXX

## Documentation

**GaussMap** routines are commented to explain their functionality to the end user. Each routine has a short description of its purpose and a list of inputs and/or outputs.
